# VivaClub

Rede social com oportunidades de renda para maiores de 18 anos.

Identidade visual: preto e dourado.

Frase: Conecte. Participe. Conquiste.

## Projeto inicial

O pacote inicial foi preparado em Next.js, TypeScript e Supabase. Ele contém telas demonstrativas para início, lives, tarefas, indicações, carteira e perfil, além de um schema SQL inicial.

**Importante:** saldos, tarefas, saques e lives ainda são demonstrativos. Antes de operar com usuários ou dinheiro real, implemente autenticação, validações no servidor, regras antifraude, pagamentos e políticas de privacidade/termos. Nunca exponha a chave `service_role` no frontend.
